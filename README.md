# About

Our prototype is the grocery extension app for the student smart home company. The main feature of
the app is the shared grocery order feature following upon Yan Lun’s Engineering Design Review
(EDR). Following this EDR, we follow the guidance of the database in the design review where we
implement the speciEic tables mentioned in the EDR for the database with PostgreSQL.

### The key pages:

- Main page (displayed when user connects to the server),
- Register page (During register process, Java code will generate a short_id and store in database.
  A UUID will be generated by PostgreSQL database)
- Login page
- Menu page (The menu page display options for users to view products, shopping cart and
  group, go back to main page, or exit)
- Checkout page (includes the total price of order, payment method and success message)
